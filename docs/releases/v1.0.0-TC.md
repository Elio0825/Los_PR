# LOS 台服 v1.0.0

首个台服发布版本，目标为 Dalamud API13 / .NET 9，使用 `PromeRotation.SDK.TC` `0.1.0-preview.2`，PR 编译引用版本为 `1.3.1.4`。

## 内容

- 与国服共用源码，以 `ClientRegion=TC` 编译 `Los.TC.dll`。
- 适配玩家对象枚举、副本成员表字段，保留原有循环、起手、热键和 Boss 上天逻辑。
- 使用独立作者标识 `Los-TC`、配置目录和发布仓库；不覆盖国服已发布的 v1.0.0。
- 按要求跳过两服黑魔技能机制对比。

## 安装

台服 PR 下载中心添加：

<https://github.com/Elio0825/Los_PR-TC/releases/latest/download/repo.json>

配置位于 `<PR配置目录>/Settings/ACRConfig/Los-TC/`；日志保存在其 `DebugLogs` 子目录。

## 验证

两服 Release 构建均为 0 警告、0 错误，各通过 20 组测试。国服使用本机真实 PR/Dalamud 安装依赖；台服使用 SDK 离线依赖及官方 Serilog 4.0.0 / Lumina 6.7.0 测试夹具，未进行台服游戏内验证。

发布包仅含 `Los.TC.dll` 与 `Los.TC.deps.json`，不附带 PR、Dalamud 或测试依赖。`repo.json` 提供 ZIP 的 SHA-256；`build-info.json` 记录实际源码 SHA、编译 SDK、参考 PR 版本和测试类型。

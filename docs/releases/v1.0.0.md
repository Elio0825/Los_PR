# LOS v1.0.0

本次发布修复黑魔纹热键的技能形态处理，并整合此前本地验证的起手、移动三连和原地黑魔纹改动。

## 黑魔纹热键

- 黑魔纹变为魔纹重置时，按实际技能判断冷却与可用性，避免黑魔纹本体没有充能时拦截重置。
- 请求保留按键时的技能意图，等待期间形态失效就取消，避免魔纹消失后误用新黑魔纹充能。
- 同一热键跨形态去重，按实际提交技能匹配 ActionEffect，避免魔纹重置成功后仍报等待回执超时。
- 增加热键拒绝、取消和技能 ID 诊断信息，以及相关回归测试。

## 本地修复合入

- 倒计时开始时暂未选中目标，可以先准备起手，在预读前绑定有效目标；补充起手准备失败的具体原因日志。
- 实装原地黑魔纹秒数；移动三连优先使用可用瞬发 GCD，没有瞬发且 GCD 空转达到设置阈值时进入 Always 队列。
- 为移动三连补充在途去重和三连状态检查，避免普通 OffGCD 路径重复派发。
- 三连咏唱、黑魔纹存在完整充能时，兼容 PR `CanCast` 在充能恢复期间返回 false 的情况。
- 增加移动、静止、GCD 空转和充能状态诊断字段。

## 兼容性

- 保持 PR API15 与 .NET 10，未新增依赖或修改公共 API。
- 发布包仅包含 `Los.dll` 和 `Los.deps.json`，`repo.json` 提供更新元数据和 SHA-256。
- 即刻进冰窄窗口问题仍保留为已知问题；此前缺失日志的三连手动热键失败尚不能归因于本次黑魔纹问题。

## 验证

- Release 主项目和测试项目构建均为 0 警告、0 错误。
- 20 个测试组全部通过，新增热键组覆盖 6 个场景。
- 本地测试依赖为 PR 1.5.10.3、Dalamud 15.0.3.5；尚未在游戏内实战验证此版本。
